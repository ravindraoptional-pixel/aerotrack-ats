# AeroTrack ATS

A browser-based React application scaffolded from the supplied `aerotrack_enterprise_ats.tsx` source file.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

This starter keeps the supplied app code and its current browser-local storage behavior. It does not yet provide cloud database storage, user authentication, or secure hosted AI resume parsing.
